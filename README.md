# App Streamlit

Aplicación mínima creada con Streamlit.

## Instalación

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## Ejecución

```powershell
streamlit run app.py
```

La aplicación se abrirá normalmente en `http://localhost:8501`.
